The Gentry for Android

Thank you for helping us test. This is an early version for Android; it isn't on the Play Store yet, so you install the file directly.

Download for Android (26 MB)

Android 7 or newer, on a 64-bit phone (nearly every phone made since 2017).

Installing

  1. Tap Download above and open the file when it finishes.
  2. Android will ask to allow installs from your browser. Choose Allow for this one install; you can switch it back off afterward.
  3. If Google Play Protect says the app is from an unknown developer, choose Install anyway. That's expected for a beta that isn't on the Play Store yet.
  4. Open The Gentry and sign in with Google or your email.

Good to know

  • This is a beta. Things will change, and some things will break. Tell us about it at support@thegentry.app.
  • The waiver text is a draft pending legal review. Please use the app for testing only, not for a real event's release.
  • New versions aren't installed automatically. Check this page for updates.
